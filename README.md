# Student Grades Management System

A simple console-based Student Grades Management System developed using Java.

## Features

- Enter student name
- Enter student roll number
- Enter marks for Java
- Enter marks for Python
- Enter marks for C
- Calculate total marks
- Calculate percentage

## Concepts Used

- Java
- Classes and Objects
- Object-Oriented Programming
- Scanner
- Variables and Data Types
- Methods
- Basic Arithmetic Operations

## How It Works

The program takes the student's name, roll number, and marks in Java, Python, and C.

It then calculates:

- Total Marks
- Percentage
